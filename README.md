# Proyecto Mercadam - Sistema de Compra Online

**Mercadam** es una simulación de un sistema de compra online, en el que los clientes pueden registrarse, autenticarse, añadir productos a su cesta y realizar pedidos con opciones de descuentos. El programa está diseñado para demostrar el manejo de clientes, productos y pedidos dentro de un sistema de compras simulado, permitiendo al usuario interactuar a través de la consola.

## Descripción del Proyecto

Este proyecto simula la interacción de un cliente con un sistema de compra online de productos alimenticios y otros artículos básicos. El cliente puede iniciar sesión, seleccionar productos de una lista, aplicar descuentos (como promociones de 3x2 o un 10% de descuento) y finalmente realizar un pedido. 

Las funcionalidades incluyen:
- Registro de clientes con contraseñas aleatorias.
- Proceso de autenticación para iniciar sesión.
- Visualización y selección de productos disponibles.
- Creación de un pedido donde el cliente puede añadir productos al carrito.
- Aplicación de promociones de descuento en los productos del carrito.
- Resumen del pedido y de los productos añadidos.
